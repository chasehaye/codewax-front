# CodeWax — Frontend

The web app for [CodeWax](https://codewax.fyi): add a GitHub repository, let it be
indexed, and chat with your codebase. Answers are generated by Claude, grounded in code
retrieved from the repo via vector search.

**Backend:** https://github.com/chasehaye/codewax-back

## Stack

- **Next.js 16** (App Router) + **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **react-markdown** for rendering chat responses
- Streaming responses from the API (`src/lib/send-request-stream.ts`)

## Requirements

- Node.js 20+
- A running [CodeWax backend](https://github.com/chasehaye/codewax-back)

## Getting started

```bash
git clone https://github.com/chasehaye/codewax-front
cd codewax-front
npm install
cp .env.template .env.local   # point NEXT_PUBLIC_API_URL at your backend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment variables

Copy `.env.template` and set:

| Variable | Description |
| --- | --- |
| `NEXT_PUBLIC_API_URL` | Base URL of the CodeWax backend API (e.g. `http://localhost:8080`) |

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build (port `13000`) |
| `npm run lint` | Run ESLint |
| `npm run format` | Format with Prettier |
| `npm run check` | Check formatting without writing |

## Project layout

```
src/
  app/          App Router routes (auth, conversations, projects/repos)
  components/   Shared form and layout components
  features/     Feature modules: auth, conversation, repository, profile, home
  lib/api/      Typed API clients for the backend
  providers/    React context (user, navigation)
```
